# Daily Chartbook Studies

This repository powers [studies.dailychartbook.com](https://studies.dailychartbook.com), a static site for interactive Daily Chartbook backtest dashboards and market studies.

The site is built with plain HTML, CSS, and JavaScript, then published through GitHub Pages. Each study is packaged as a standalone dashboard with charts, summary statistics, signal analysis, and supporting tables.

Visit the live site:

[https://studies.dailychartbook.com](https://studies.dailychartbook.com)
